# KB Creation v1: Pipeline Quick Runbook

This runbook provides the direct, copy-pasteable execution workflow for the **Central Knowledge Base & CPT Ontology Mapping Engine** (`KB creation v1`).

For the comprehensive architectural specification, database schemas, and tiering definitions, see **[docs/END_TO_END_GUIDE.md](docs/END_TO_END_GUIDE.md)** and **[docs/DESIGN.md](docs/DESIGN.md)**.

---

## 1. Quick Execution Workflow

From the `KB creation v1` directory in PowerShell:

```powershell
cd "c:\Users\dell\Documents\Payer Policy\KB creation v1"

# Step 1: Initialize Database Schema (DuckDB)
python scripts\initialize_database.py

# Step 2: Build ICD-10-CM Diagnosis Search Index (SQLite)
python scripts\build_icd10cm_index.py

# Step 3: Ingest & Map Policies to CPT/HCPCS (Run per payer)
# UnitedHealthcare
python scripts\map_policy_cpt_codes.py --input data\input\extraction_rules_uhc.json --payer-profile unitedhealthcare

# Humana
python scripts\map_policy_cpt_codes.py --input data\input\extracted_rules_humana.json --payer-profile humana

# Step 4: Compare Policies & Identify Cross-Payer Rule Gaps
python scripts\compare_policies.py

# Step 5: Run Structural Integrity & Referential Checks
python scripts\validate_results.py

# Step 6: Execute Automated Test Suite (60 passed, 3 skipped, 0 failures)
python -m pytest tests
```

## 3. Key Primary Outputs (`data/exports/`)

| File | Content |
| :--- | :--- |
| `data/exports/policy_cpt_mappings.csv` | Master crosswalk linking policies to CPT/HCPCS codes with confidence tiers A–E, scores, and provenance |
| `data/exports/mapping_evidence.json` | Complete forensic evidence trail (text snippets, sentence offsets, CUIs, match methods) |
| `data/exports/code_mentions.csv` | Every regex-detected code token across all policy texts and tables |
| `data/exports/policy_comparison_report.csv` | Cross-payer comparison matrix of equivalent, differing, and conflicting policy rules |
| `data/exports/rule_gap_report.csv` | Granular policy rule discrepancies and missing coverage criteria |
| `data/exports/mapping_quality_report.md` | Executive health dashboard, confidence distribution, and vocabulary coverage |
| `data/exports/audit/audit_summary.md` | Schema validation, section extraction status, and mapping provenance summary |
| `database/payer_policy_kb.duckdb` | Persistent 196 MB embedded DuckDB analytical database |
