# Multi-Payer Billing Rule Comparison Platform

Automated cross-payer comparison pipeline for health plan billing rules across **UnitedHealthcare (UHC)**, **Aetna**, and **Humana**.

---

## 1. Overview

The platform ingests the normalized billing rules generated by each payer's extraction pipeline, matches overlapping rules using a 4-signal composite similarity model, classifies the findings, detects cross-payer policy conflicts, and surfaces coverage gaps where one payer enforces rules that others do not.

---

## 3. Architecture & Pipeline Components

```
                        ┌───────────────────────────────────────┐
                        │   Input Rules (UHC, Aetna, Humana)   │
                        └───────────────────┬───────────────────┘
                                            │
                                            ▼
                                     [ ingest.py ]
                           Canonical Schema & Category Mapping
                                            │
                                            ▼
                                     [ matcher.py ]
                        4-Signal Composite Scoring (Jaccard + Fuzzy)
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    ▼                                               ▼
            [ comparator.py ]                               [ gap_finder.py ]
   Classification: EQUIVALENT / DIFFERING /           Unmatched Rules by Severity:
   CONFLICTING / NOT_ASSESSABLE                        HIGH / MEDIUM / LOW
                    │                                               │
                    └───────────────────────┬───────────────────────┘
                                            │
                                            ▼
                                     [ reporter.py ]
                        Multi-Sheet Excel Workbook (.xlsx)
                           Executive Summary (.md)
```

### Module Breakdown

* **`ingest.py`**:
  * Unifies column names across payers (UHC custom schema vs. Aetna/Humana schema).
  * Normalizes 20+ payer-specific category labels into 10 canonical categories.
  * Standardizes CPT/HCPCS code lists, modifiers, and clean text fields.

* **`matcher.py`**:
  * Evaluates candidate pairs across different payers.
  * Uses a 4-signal composite matching algorithm:
    * **Code Jaccard Overlap**: 40% weight
    * **Policy Title Fuzzy Similarity**: 25% weight
    * **Rule Statement Fuzzy Similarity**: 20% weight
    * **Canonical Category Agreement**: 15% weight
  * Tiers matches into **STRONG** ($\ge 0.70$), **POSSIBLE** ($\ge 0.50$), and **WEAK** ($\ge 0.40$).

* **`comparator.py`**:
  * Performs deep comparative classification on matched pairs:
    * `EQUIVALENT`: Same clinical condition, same codes, same adjudication outcome.
    * `DIFFERING`: Same general policy/procedure, but diverging frequency limits, modifier requirements, or code scope.
    * `CONFLICTING`: Direct contradictions (e.g., Payer A allows vs. Payer B denies for the same scenario/codes).
    * `NOT_ASSESSABLE`: Incomplete or unresolvable rule text.

* **`gap_finder.py`**:
  * Detects rules present in only one payer (no match $\ge 0.40$ in either of the other two payers).
  * Categorizes gaps by operational severity:
    * **HIGH**: Denial or frequency rules attached to concrete billing codes.
    * **MEDIUM**: Conditional reimbursement, bundling, or modifier rules.
    * **LOW**: General administrative, documentation, or policy requirements.

* **`reporter.py`**:
  * Assembles the 8-sheet formatted Excel workbook and Markdown summary.

* **`run_comparison.py`**:
  * Main CLI orchestrator to run the entire pipeline end-to-end.

---

## 4. How to Run

From this directory (`Rule Comparison/`), execute:

```powershell
python run_comparison.py
```

---

## 5. Deliverables & Outputs

Output reports are written to `comparison_report/`:

1. **`comparison_report/comparison_report.xlsx`** (8-Sheet Workbook):
   * **Executive Summary**: High-level inventory, match stats, and breakdown counts.
   * **Rule Matches**: All 2,546 candidate pairs with composite and component scores.
   * **Comparison Findings**: Classification details, conflict reasons, and modifier differences.
   * **Conflicting Rules**: Filtered view of critical clinical and adjudication contradictions.
   * **Differing Rules**: Filtered view of rules with divergent constraints or codes.
   * **Coverage Gaps**: Unmatched rules with payer source, severity, and rule excerpts.
   * **Code Overlap Matrix**: Pairwise CPT/HCPCS code intersection analysis.
   * **Policy Topic Coverage**: Cross-payer mapping of policy topics.

2. **`comparison_report/executive_summary.md`**:
   * Quick-reference markdown report with top conflicting pairs and high-severity gaps.
